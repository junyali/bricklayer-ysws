# Resources
Here are some useful resources and links that I've always utilised back in my days of Roblox development.

Don't be afraid to look elsewhere, you have the entire internet at your hand so use it! Google search queries (e.g., \[x problem I'm having\] site:devforum.roblox.com), Reddit, Youtube, Discord communities, anything!

## Finding help / troubleshooting problems
- [Google (seriously)](https://google.co.uk/)
- [Devforum](https://devforum.roblox.com/) - Amazing guides, tutorials, discussions that are still valid even from the 2010s. It has become far more immature in the recent years, but older topics are still good!
- [Creator Hub Docs](https://create.roblox.com/docs/) - Probably one of the best documentation for a game engine I've ever read. It's seriously good, PLEASE use it!!
- [Roblox Lua Style guide](https://roblox.github.io/lua-style-guide) - Not really related information-wise, but helps you to write better styled code in Luau
- [Rojo Docs](https://rojo.space/docs/v7/) - RTFM basically
- [Advanced Roblox Project Setup by sleitnick](https://www.youtube.com/watch?v=sEnNjNakXT8/) - This video was incredibly useful to me back when I started. It's quite outdated now, and you can skip many parts as they're not required for shipping your game, but it gives you a general idea of what your workflow should look like!
