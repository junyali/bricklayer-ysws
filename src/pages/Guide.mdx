# A Brickie's guide to making your own game in Roblox
Hey fellow Brickie! Want to start making your own game in the Roblox engine but no idea where to begin? I don't blame you! This guide walks you through the **absolute minimum** you need to get your project started for Bricklayer.

**Reminder**: To qualify for submission, you **MUST** add your own features.

**Read over the [FAQ](/faq) first before asking any questions in the Slack or starting this guide!**

## Platform Introduction

Before you can make a project, you'll need to set up some stuff.

### Roblox Account
If you don't already have one, head to the [Roblox website](https://www.roblox.com/) and create an account. [It's FREE!](https://youtu.be/97dyt7MXWpo?t=26)

You don't need anything special, but make sure you fill in the information correctly! Be sure to verify your email address in settings afterwards.

### Roblox Studio
Roblox Studio is the desktop app where you lay bricks, build your game, and test it. Think of it as any other game engine software!

#### Download links
*Sidenote: Roblox Player is **NOT** required, unless you want to play games in a true multiplayer environment as-is.*

- Windows/macOS: Install Roblox Studio from the [Create](https://create.roblox.com/landing) page or the docs [here](https://create.roblox.com/docs/en-us/tutorials/curriculums/studio/install-studio).
- Linux: Roblox doesn't officially support Linux, but you *can* run it using community solutions supported by the Roblox engineers themselves.
    - For more information, see [Vinegar](https://vinegarhq.org/)

### GitHub Account + Repo
Or some other Git-based hosting solution.

Your project **must** be open-sourced, available and public. Private repositories are not accepted for submission.

## Project Setup
This section is going to be a whole can of worms, so strap in!

Here, you'll be actually setting up your project in your IDE which can be synced to your game in Roblox Studio.

### Install Visual Studio Code
VS Code is where you'll do all your programming work with time tracking in Hackatime and syncing through Rojo.

Roblox Studio does offer a built-in scripting interface, however it's volatile and I personally don't like it. It's also hard to confirm the accuracy of hours spent.

You're more than welcome to use your preferred IDE, however you'll be missing out on a ton of useful VS Code Extensions such as LSPs.

Download VS Code [here](https://code.visualstudio.com/).

I **highly recommend** you download VS Code extensions to help you with writing code for the Roblox engine - see my list [here](/resources#plugins-extensions).

### Install Rojo
Rojo (pronounced as roh-ho) connects to your VS Code project to Roblox Studio, letting you write scripts and syncing code in real-time rather than you using in the in-studio editor (and making it possible for you to track your time + commits).

Rojo exists as two things you need to install: one on the **IDE** side, and one on the **Roblox** side.

You can install Rojo as **either** a VS Code extension, or as CLI.

You'll also need to install the Rojo plugin for Roblox Studio.

See the [Rojo Docs](https://rojo.space/docs/v7/getting-started/installation/) on installation.

### Install Aftman/use your favourite toolchain manager
In this guide I'm going to be using Aftman, but you can use whatever toolchain manager you want - as long as it works!

Make sure you have [Rust](https://rust-lang.org/learn/get-started/) installed and PATH configured!

See the [GitHub Repository](https://github.com/LPGhatguy/aftman) for installing Aftman.
